# Changes

## 1.1.0

- Added six dalmatics, a cassock, surplice, and six interchangeable altar frontals.
- Added a 27-slot sacristy cabinet, Advent wreath, votive rack, fourteen-number Stations plaque, incense burner, two devotional statues, credence table, and ambo.
- Added an eight-use refillable aspergillum, altar bell, processional cross, scapular, beeswax, and unconsecrated altar bread.
- Added a Latin prayer book and a Stations companion; expanded the field guide to sixteen pages.
- Made pews usable as seats, with automatic removal of abandoned seats and cleanup when a pew breaks.
- Added persistent incense fuel and preservation of altar frontal colors and station numerals when mined.
- Expanded the generated chapel with both missals on lecterns, all fourteen Stations, statues, furniture, and a stocked cabinet.
- Expanded survival crafting to 64 recipes, with original models and textures for every new item.
- Added seven Minecraft integration tests; all eighteen pass. Native asset parsing and text layout checks cover the expanded content.
- Added a release ZIP builder with source, documentation, validation results, and SHA-256 checksums.

## 1.0.0

- Initial tabernacle, missal companions, vestments, holy water/fonts, medals, rosary, thurible, chapel furnishings, and builder.
